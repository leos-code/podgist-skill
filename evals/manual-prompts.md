# Manual Eval Prompts

1. Search ambiguity
   `帮我找一期聊 OpenAI 的 Lex Fridman podcast，然后先给我候选项，不要直接下载。`

2. Long episode
   `搜索 Huberman podcast 关于 sleep 的一期，做完整分析并给我快速跳听时间点。`

3. Chinese episode
   `找一期中文播客聊 AI 创业，帮我判断值不值得听。`

4. Timestamp utility
   `只想听他讲创业低谷的部分，给我时间段。`

5. Preview fallback
   `如果音频直链没有了但还有 preview，明确告诉我并继续处理。`

6. Follow-up reuse
   `基于刚才那期，回答：他在哪一段提到融资策略？不要重新转录。`
